Ayuda del sistema SMRI

Esta seccion resume el uso principal del sistema de monitoreo de riesgos industriales, sus roles y las detecciones realizadas con vision artificial.

Como iniciar sesion

Ingresa desde la pantalla de login con el usuario o correo y la contrasena asignada. Las credenciales son creadas previamente por un Admin o un Jefe autorizado.

Como registrarse

El sistema no permite registro publico. Para crear una cuenta, el Admin o el Jefe debe ir a Configuracion, abrir Usuarios y roles, ingresar los datos del usuario y asignar el rol correspondiente.

Como usar el sistema

El Dashboard muestra el resumen general de eventos y alertas. La seccion Alertas permite revisar incidentes detectados. Los roles con permisos administrativos pueden gestionar usuarios, camaras e informes segun su nivel de acceso.

Que detecta el sistema

El sistema detecta rostros autorizados o desconocidos, incumplimientos de EPP, objetos de riesgo como cuchillos, tijeras, celulares, bolsos o mochilas, y accesos no autorizados dentro de las areas monitoreadas.

Roles del sistema

Admin tiene acceso total. Jefe puede crear Jefes y Operadores, pero no accede al panel administrativo ni a la gestion de camaras. Operador tiene acceso limitado al Dashboard, Alertas y configuracion personal.
